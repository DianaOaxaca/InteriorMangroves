# Algorithmic provenance and software citations

## Statistical and network algorithms

- Centered log-ratio transformation follows Aitchison (1986).
- Phyloseq object handling follows McMurdie & Holmes (2013).
- Ridge-regularized partial-correlation inference follows the regularized inverse-covariance / partial-correlation logic of Schäfer & Strimmer (2005).
- Bootstrap resampling follows Efron & Tibshirani (1993).
- Depth trend testing uses Spearman rank correlation between ordinal sediment depth horizons and bootstrap network metrics.
- Kruskal-Wallis tests summarize distributional differences among sediment depth horizons.
- Louvain community detection follows Blondel et al. (2008).
- Network metrics and graph operations use igraph following Csardi & Nepusz (2006).
- Plotting uses ggplot2 following Wickham (2016).
